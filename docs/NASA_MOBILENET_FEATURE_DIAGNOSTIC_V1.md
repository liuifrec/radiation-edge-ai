# MobileNetV2 training-only attribution protocol

This diagnostic uses the standard INT8 female-fold BIE and the original 192 training calibration nuclei. The archived 16-nucleus pilot forms one descriptive panel, including its known large errors. The additional 24 nuclei come from the remaining 176 nuclei. Each of the four sources contributes one minimum FP32 prediction (lexicographic sample ID breaks ties, including zeros) and five positive predictions at ranks nearest the minimum, first quartile, median, third quartile and maximum. Select distinct ranks with lexicographic ID tie-breaking. No fixed-point output enters confirmation selection. These nuclei share training/calibration sources and support a training engineering comparison.

The selection receipt binds the model, export, checkpoint, original and optimized graphs, BIE, references, quantization descriptors and per-nucleus array hashes. The named capture runs offline with the pinned vendor image and unchanged BIE. Analyze the two panels separately. Report signed errors, absolute errors, reference and fixed ranges, zero fractions, channelwise errors, code-limit occupancy and source/prediction strata. Analyze nuclear intensity and radiation condition descriptively where they have observations.

Use signed preactivation and rectified endpoint decompositions. Compare the original affine weights and bias against the optimized affine parameters. Compute FP32 spatial global averaging and the original affine head on the native pre-pool tensor. Apply the same head to the native pooled vector. Inspect BIE flatten, native Gemm scalar, native ReLU and gathered output as separate boundaries. The difference between an ideal rectified native head and the observed native ReLU measures the encoding at that boundary. The Gather difference measures the final transport/reshape contribution.

For accessible sequential feature boundaries, feed original-BIE activations through an optimized FP32 suffix. First replay each suffix on its own FP32 boundary to verify the FP32 head to absolute tolerance 0.00001. A change observed between adjacent sampled boundaries localizes a difference to that interval under the FP32 suffix. This does not identify an internal device arithmetic defect. Verify each native tap's exact tensor name, metadata, signed fixed words, axes and dimensions against the native float dump. Account for the native eight-decimal text precision when checking decoded floats. Check that the unchanged FP32 graph and its tapped version agree at the endpoint. Report runtime options and reconcile with archived full-graph FP32 predictions.

`scripts/windows/mobilenet_feature_capture.py prepare` freezes a new panel. Pass its output directory to the `capture` command. The four biological sources, the 16 historical pilot IDs and their published FP32 predictions remain fixed. Keep each readout external and pass its selection digest to the analyzer. No candidate advances from this training-only protocol.
